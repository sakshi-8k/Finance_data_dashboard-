# Finance_data_dashboard
This project is a two-page financial analytics dashboard built on a transactions fact table, a customer dimension table, and a custom date table. It's designed to give both a high-level executive summary and a detailed, filterable transaction register.

Pages

1. Main Dashboard

Headline KPI cards: Total Amount, Total Transactions, Average Transaction Value, Total Fees, Total Tax
Dynamic KPI card driven by a measure-switcher (field parameter) and year selector
Monthly trend area chart of Total Amount
Donut charts: Total Amount by Transaction Status, and by Customer Gender
Bar charts: Total Amount by Customer Segment, and by State
Summary table by Transaction Type
Slicers: Year, Dynamic Measure, Occupation, Merchant Category

2. Transactions

Same KPI/context cards as the Main Dashboard for consistency
Detailed transaction-level table: Transaction ID, Customer Name, Date, Type, Status, Gender, Segment, State, Amount, Fees, Tax
Same slicer set for consistent filtering
Quick page navigation page
